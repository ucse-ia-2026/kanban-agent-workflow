# Kanban agent workflow

Este repositorio permite practicar trabajo en equipo con Git, agentes de programación y Kanban.

El trabajo se organiza mediante issues y un tablero Kanban. Cada cambio se realiza en una rama, se propone mediante una pull request y es revisado por otra persona antes de integrarse.

Consulta [CONTRIBUTING.md](CONTRIBUTING.md) para seguir el flujo de colaboración.
